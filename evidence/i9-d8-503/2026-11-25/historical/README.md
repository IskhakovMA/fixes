# Исходная локальная поставка

Архив сохранен побайтно и проверен по приложенному SHA‑256, CRC и внутреннему манифесту. Это исходные локальные квитанции. В нем сохранен исторический пример с временным каталогом стенда. Для запуска используйте актуальный [D8 quickstart](../D8_QUICKSTART.md). Внешний манифест каталога публикации учитывает последующие уточнения и не подменяет манифест внутри архива.
