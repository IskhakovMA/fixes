# Независимые заключения для публикации

| Направление | Проверка | Вывод |
|---|---|---|
| Git / воспроизводимость | Независимое чтение GitHub, точная интеграционная база, отсутствие одноименной ветки и PR, правила CI | Репозиторий публичный. Точный базовый SHA совпал. Для ветки docs активный workflow требует отдельного запуска по `workflow_dispatch`. Переданы проверки родителей, blob SHA, PR и точного CI |
| Privacy / security | Независимый разбор исходного ZIP, CRC, 35 хешей, анализ файлов, отсутствие симлинков, clinic DB, секретов и production URL, Gitleaks 8.28.0 | Исходный пакет пригоден как исторический архив. В актуальной инструкции заменен устаревший временный путь. Проверка дополнительных файлов и staged diff выполнена перед публикацией |
| D8 / браузер | Независимое чтение launcher и старых результатов, точность 48 строк, трех руководств и платформенных границ, анализ Back/Forward | Подтверждено разделение evidence и чистого точного runtime. Добавлена обработка штатного Ctrl+C. Сохранены исходные guards и assertions. Предложено ожидание конкретного перехода вне этого изменения |
| HTTP 503 / медицинские транзакции | Независимый пересчет CRC и SHA, проверка квитанций и контрактов v33 | 8 отдельных некодированных синтетических 503, подтвержденный пост-COMMIT 500 с безопасным повтором создания тем же ключом. Исторические 0/2 остаются UNKNOWN. Добавлены матрица действий и предложение по корреляции |
Главная сессия сверила выводы по исходникам и повторила технический D8 и полный Chromium Back/Forward на принятом SHA. Независимые заключения не являются ручными квитанциями D8.
