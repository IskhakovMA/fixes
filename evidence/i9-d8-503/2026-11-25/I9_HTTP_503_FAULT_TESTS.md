FastAPI TestClient, отдельные синтетические SQLite в pytest basetemp. Производственные данные и слушающие сетевые сокеты в этих экспериментах не использовались.

Проверки из репозитория запущены с `-p no:cacheprovider --basetemp <scratch>`. Файл `i9_503_receipts.py` добавляет только синтетическое наблюдение TestClient, сохраняя имя теста, метод, статус, машинный код, набор ключей отказа и полное время запроса. Тела, URL, медицинские и сессионные значения не выгружаются. Отдельное время захвата writer, SQLite extended error code и исключение сервера наблюдателем не измерены.

Новые uncoded 503 относятся к подтвержденным путям защитного отказа при инъекции. Для связи с историческими случаями отсутствует корреляция запросов и фаз транзакции.
