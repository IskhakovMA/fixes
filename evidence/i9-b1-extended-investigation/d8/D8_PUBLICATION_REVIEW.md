# Проверка безопасности материалов D8

Проверяемый продукт — `3a0cb5db434032b3f7b6370c305c558a4b5d331c`. Операторский набор воспроизводит проверку на синтетическом loopback-стенде.

Допуск к публикации относится только к файлам из списка. Манифест верхнего уровня evidence-ветки должен включать именно эти файлы при копировании подкаталога.

| Файл | Что проверено |
|---|---|
| `README.md` | Переносимые команды с переменными путей. Адреса ограничены loopback. |
| `I9_D8_MAC_OPERATOR_STEPS.md` | Сценарии и ожидаемые результаты. Метка фикстуры явно синтетическая. |
| `I9_D8_B1_RECEIPTS.tsv`, `I9_D8_MAC_SESSION_RECEIPTS.tsv` | Пустые поля наблюдений, озвучивания, идентификации оператора и ссылок на доказательства. Только NOT TESTED и BLOCKED. |
| `OPERATOR_RUNNER_SMOKE.json`, `REFERENCE_TECHNICAL_SMOKE.json` | Только технические поля, связи с рабочей средой нет. |
| `D8_B1_ROUTE_SMOKE.json` | Закрытые технические названия проверок и HTTP-статусы. |
| `d8_operator.py`, `d8_route_smoke.py` | Учетные данные генерирует и использует только одноразовый upstream-стенд. Скрипты не сохраняют и не выводят их в квитанции. |
| `stand/d8_stand.py`, `stand/launch-d8.sh` | Адаптированный опубликованный изолированный launcher. Жестко ограничивает SHA, loopback и синтетические зависимости. |
| `D8_STATUS.md`, `D8_PUBLICATION_REVIEW.md` | Технический статус проверок и прозрачность ручных ограничений. |

Gitleaks 8.28.0 и точный path allowlist подтверждены. Дополнительная проверка не обнаружила личных абсолютных путей, приватных IP-адресов, секретоподобных параметров или наблюдений, которые могли бы содержать медицинские данные. Сырые логи Uvicorn, учетные данные фикстуры, профили Safari, исходные HTTP-ответы, Database/WAL/SHM, временные runtime-файлы и личные пути исключены. Поле с локальным портом не является адресом инфраструктуры.
