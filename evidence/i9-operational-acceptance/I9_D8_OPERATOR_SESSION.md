## Оператор Mac

1. Только когда готовы к ручной сессии, запустите локальный `START_D8_B1_LOCAL.command` через Terminal. Для запуска на другой машине используйте опубликованный README с точным чистым B1 checkout. Выберите чистый профиль Safari без синхронизации и расширений. Откройте только выданный адрес loopback и войдите под требуемой синтетической ролью. Фикстура доступна локально по пути, показанному launcher.
2. Включите VoiceOver клавишами Command+F5 и разрешите в Safari переход Tab по всем элементам. Используйте [16 шагов из опубликованного руководства](https://github.com/IskhakovMA/fixes/blob/2733592fae05468ce8206c6a9900d3adaec606b5/evidence/i9-b1-extended-investigation/d8/I9_D8_MAC_OPERATOR_STEPS.md). Проверьте обе темы, физические клавиши Tab/Shift+Tab, стрелки и Escape, порядок фокуса, реальный Back/Forward, историю, диалоги, черновики и ожидаемые отказные состояния.
3. Внесите в отдельную копию Mac TSV фактическое озвучивание, фокус, результат, браузер и систему, тему, роль, CSS-ширину и настоящий Safari Page Zoom. Используйте нативные 100%, 200% и 400% только при наличии их в браузере. Для отсутствующего значения сохраняйте подслучай открытым. Значения CSS, responsive mode и масштаб экранной лупы не подтверждают нативный zoom. При нескольких профилях или темах делайте отдельные строки `subcase`.
4. Запишите PASS только для реально выполненной проверки с очищенной квитанцией. Для реального 409 используйте две изолированные синтетические сессии. Неподготовленные транспортные сбои, недоступные фикстуры и ненаблюденные 401/404 или поздний 200 остаются открытыми подслучаями. После выполнения остановите стенд Ctrl+C. Техническая квитанция записывается после подтверждения освобождения порта и удаления синтетической SQLite и фикстуры.
