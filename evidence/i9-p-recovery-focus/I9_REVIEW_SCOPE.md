# Независимые направления проверки

| Направление | Проверка и ограничение |
|---|---|
| A — фокус | Чистый B1 с кейсом ожидаемого FAIL и финальный продукт прошли один и тот же реальный поток событий. Отдельный reviewer воспроизвел 6 native zoom случаев на финальном байт-в-байт frontend, в том числе масштаб 400%, и проверил исходное предложенное исправление, epoch и владение фокусом. |
| B — безопасность | Проверены реальный logout/401/reauth, доступ и clearing после действительного reassignment 404, вкладки со сменой пользователя, отсутствие старого payload и клинических writes от retry. Коды транспортных вариантов разнесены. Сравнение точного diff исключает изменения RBAC, backend, схемы и audit. |
| C — статистика | 20 естественных 409 повторно пересчитаны из первоначальных private receipts. First-read и готовый UI используют один и тот же offered знаменатель. Время HTTP PATCH только ограничивает возможное время COMMIT. Точный источник естественных конфликтов не выводится из корреляции. |
| D — harness | Новая фикстура с версиями консилиума, фильтром и отрицательными областью и фасетами проверена на неизменном B1. По две области нагрузки и адресные self-tests; полный P не запускался. |
| E — публичная публикация | Сверены точный Git diff, изменения разрешенных путей, файлы fixture-only source и обезличенные результаты. Gitleaks 8.28.0, SHA-256, отсутствие HTTP payload, credential receipts, профилей браузера, SQLite/WAL/SHM и личных путей подтверждаются отдельными проверками перед отправкой. Низкоуровневые приватные логи Playwright исключены. |

Известные ограничения для следующего шага: ручное озвучивание и фокус Safari/VoiceOver, платформенные D8, репрезентативное подтверждение P с более длинными блоками, decision record владельца по HTTP 503 и точный новый CI полного состава после согласования History + focus. Эти блокеры не скрываются успешной адресной проверкой.
