# Clinic Tracker · Fast Track F5

F5 связывает «Пульс клиники», «Мой день», действующую серверную аналитику и явную CSV-отчетность. Интерфейс сохраняет Stage 3.5 и Staff-UX. Серверные медицинские права, методы расчета, схема SQLite v33, операции записи и read-release с аудитом остаются в утвержденном виде.

## Что может сотрудник

- **Руководитель.** Выбрать показатель и поддерживаемый этап в «Пульсе клиники», открыть серверную детализацию по 50 строк, перейти к доступной карточке и вернуться к тем же фильтрам и странице. Возврат повторно читает данные и восстанавливает фокус на доступной строке. Затем можно явно запросить серверный CSV.
- **Врач.** Перейти от выбранного раздела «Моего дня» к персональным пациентам, просроченным событиям или чек-листам. Просрочка ведет во вкладку событий. Изменение фактической даты использует действующую проверку версии. После него аналитика получает новый серверный результат.
- **Отчетность.** Доступны сводка, этапы, нагрузка, качество данных, чек-листы и уведомления. Детальные отчеты доступны по кодам проблем и этапам чек-листов. Подпись объясняет область, фильтры, время и имя файла. Обязательные проверки остаются на сервере.

## Открытые границы

Точное раскрытие только активных маршрутов потребует согласованного серверного фильтра, если владелец выберет эту задачу. Текущая подпись явно указывает, что список показывает весь доступный отфильтрованный набор. У существующего CSV нагрузки действует лимит 50 строк. Ручная D8 остается отдельным этапом. Для production сохраняется NO-GO. Спринт F5 не меняет статус Pilot P, двух исторических HTTP 503, недельного расписания или дефектуры ЦАОП.
