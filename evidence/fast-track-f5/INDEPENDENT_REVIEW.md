# F5 · независимые проверки

| Направление | Проверенная гарантия | Доказательство |
| --- | --- | --- |
| Серверная семантика | Summary описывает текущее состояние. Динамика использует серверные календарные даты. Один пациент может дать несколько событий или замечаний. Точный список активных маршрутов отсутствует в текущем `patients` drill-down. | `CONTRACT_AND_LIMITS.md`, тесты срока и единиц в `F5_HOSTED.json`. |
| RBAC и медицинская целостность | Сервер ограничивает организационные данные областью сессии. Врач не видит чужую нагрузку. После переназначения объекта 404 не открывает карточку. После реального выхода задержанный HTTP 200 не раскрывает данные. Версионированное действие записывает один факт. Контрольное переназначение ожидаемо и учитывается отдельно. | `F5_HOSTED.json`, `HISTORY.json`, верификация всех прочитанных данных и клинических строк временной базы. |
| CSV и аудит | Явный POST вернул ожидаемое имя, BOM и фактические CSV-байты. SHA-256 вкладки скачивания совпал с атомарным серверным манифестом аудита. Проверены набор разрешенных объектов, отказ 403 при отсутствующей CSRF, анонимный 401 и отсутствие файлов при отказе. Существующие backend-тесты проверяют neutralization формул, допустимые поля и отказ аудита. | `F5_HOSTED.json`, `F5_CI.json`. |
| Stage 3.5 и интерфейс | Сохранены утвержденные компоненты и визуальные токены. Отдельно проверены ролевые состояния, вкладка активного события, клавиатура, возврат к строке после Back и новой проверки сессии. | `DESIGN_REVIEW.md`, `F5_HOSTED.json`, синтетические PNG. |
| CI и публикация | SHA и дерево связаны с запуском. Полный exact-once проверяется по исходным GitHub Actions логам, где зафиксирован digest коллекции. Также проверяются canary Gitleaks и три фактических сканирования. Для публичного evidence используется список разрешенных файлов, отдельное сканирование и обратное чтение. | `F5_PROVENANCE.json`, `F5_CI.json`, `SHA256SUMS`. |

Локальный адресный backend-прогон файлов analytics, frontend CSP и WP-G export завершился с результатом 92 passed. Три независимых проверки CSV и области доступа использовали уже существующие тесты, в том числе семь WP-G CSV сценариев. Локальные прогоны помогают диагностике. Требования к итоговому дереву задают GitHub CI и hosted Chromium.
