## Результаты маршрута

Уже действующие клинические правила и права формы сохранились. Добавлены
сводка ошибок с переходами к полям, предварительный просмотр фактически
отправляемого события и прямое действие записи на консилиум для разрешенной
роли. Пациент закреплен по актуальному идентификатору карточки, время выбирается
из действующего расписания. Смена этапа, ручная отметка решения и подписание
остаются отдельными действиями.

После потери настоящего ответа 201 форма делает ноль автоматических повторов.
Явная проверка отправляет неизменные ключ и тело. Сервер вернул исходный ID,
а использование того же ключа с измененным телом получило 422. Отдельная
подтвержденная операция с возможным дублем сохранила действующий протокол 409
и обязательную причину.

Сквозной сценарий на SQLite v33 сверил три создания, один аудит повтора,
один аудит записи на консилиум и 11 SHA-256 манифестов чтения. Проверены актуальные
реестр, «Мой день», календарь, внутренние уведомления и персональная аналитика.
Медицинский маршрут и начальное событие сохранились после записи.
